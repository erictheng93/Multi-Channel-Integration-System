🧪 QR Background Preload 測試頁面

Phase 1 - MVP 功能驗證

⏳ 待執行 Test 1: 開發伺服器啟動

步驟 1: 啟動前端開發伺服器

在終端機執行以下命令：

cd frontend
npm run dev
預期結果：
✅ 看到 "VITE vX.X.X ready in XXXms"
✅ 看到 "Local: http://localhost:3000/"
✅ 無編譯錯誤

步驟 2: 訪問團隊管理頁面

開啟瀏覽器訪問：

http://localhost:3000/team

⏳ 待執行 Test 2: Console 日誌檢查

步驟 1: 開啟瀏覽器開發者工具

按 F12 或右鍵 → 檢查 → Console 分頁

步驟 2: 檢查預載啟動日誌

應該看到以下日誌（依序出現）：

🚀 TeamManagement mounted 🔄 開始載入團隊列表... ✔️ 團隊數據已更新: X 個團隊 🚀 [TeamManagement] Starting background QR preload for X teams 🎯 [QRPreload] Phase 1: Loading 3 priority teams 📥 [phase1] Loading QR for team X (團隊名稱) ✅ [phase1] Loaded QR for team X in XXms ⏳ [QRPreload] Phase 2: Loading X teams (idle time) ...

步驟 3: 驗證 Feature Flag

在 Console 執行：

window.featureFlags.list()
預期結果：
✅ 看到 QR_BACKGROUND_PRELOAD: Enabled ✅, Rollout 100%

⏳ 待執行 Test 3: 功能運作測試

步驟 1: 測試點擊延遲

在 Console 執行：

console.time('QR Click')

然後立即點擊任何團隊的「QR 碼」按鈕

在 Console 再執行：

console.timeEnd('QR Click')
預期結果：
✅ 延遲時間 < 100ms（理想 < 50ms）
✅ QR Code Modal 立即顯示

步驟 2: 查看效能指標

在 Console 執行：

const metrics = qrPreloadService.getMetrics() console.table(metrics)
預期結果：
✅ Total Teams = 團隊數量
✅ Loaded Successfully ≈ Total Teams
✅ Failed = 0
✅ Cache Hit Rate > 90%
✅ Avg Load Time < 200ms

⏳ 待執行 Test 4: Feature Flag 切換測試

步驟 1: 禁用背景預載

在 Console 執行：

window.featureFlags.disable('QR_BACKGROUND_PRELOAD')

重新整理頁面 (F5)

預期結果：
✅ Console 顯示：🚫 [TeamManagement] Background QR preload is disabled
✅ 不再看到預載相關日誌

步驟 2: 重新啟用

在 Console 執行：

window.featureFlags.enable('QR_BACKGROUND_PRELOAD')

重新整理頁面 (F5)

預期結果：
✅ 背景預載功能恢復運作

✅ 測試檢查清單

  • 開發伺服器成功啟動（無錯誤）
  • 頁面載入後看到背景預載日誌
  • Feature Flag 功能正常運作
  • 點擊「QR 碼」按鈕延遲 < 100ms
  • 效能指標顯示快取命中率 > 90%
  • Feature Flag 切換功能正常
  • 無 Console 錯誤或警告

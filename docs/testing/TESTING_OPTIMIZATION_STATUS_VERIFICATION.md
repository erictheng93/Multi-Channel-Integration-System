- `StatusBadge.test.ts` - 2個失敗

**技術根因**: Vue Test Utils 與 JSDOM 的事件構造器兼容性問題

### 2. 錯誤訊息本地化不一致（高優先級）🟡

**影響範圍**: 8 個後端測試失敗
**問題類型**: 中英文錯誤訊息不匹配

**具體錯誤示例**:
```
Expected: "獲取對話列表失敗"

Expected: "對話結束失敗"

```

### 3. 資料結構返回問題（高優先級）🟡

**影響範圍**: 大量後端測試失敗
**問題類型**: API 響應資料結構不匹配

**具體錯誤示例**:
```
AssertionError: Target cannot be null or undefined.

```

# 活動記錄功能測試指南

## 🎯 測試目標

驗證以下功能是否正常工作：
1. Admin 可以查看所有活動記錄
2. Agent 只能查看自己的活動記錄
3. 各種操作會自動記錄活動
4. 權限控制正確實施

## 📋 測試步驟

### 1. 基礎功能測試

#### 1.1 檢查導航選單
- [ ] 以 Admin 身份登入系統
- [ ] 檢查左側導航選單是否顯示「活動記錄」選項
- [ ] 點擊「活動記錄」，確認頁面正常載入

#### 1.2 檢查活動記錄頁面
- [ ] 頁面標題顯示「活動記錄」
- [ ] 篩選區域正常顯示（用戶、操作類型、資源類型、時間範圍）
- [ ] 活動記錄列表正常顯示
- [ ] 分頁控制項正常顯示

### 2. 權限測試

#### 2.1 Admin 權限測試
```
測試用戶：admin@dacit.net / 16011587DaC
```
- [ ] 登入後檢查活動記錄中是否有登入記錄
- [ ] 在用戶篩選中可以看到所有用戶選項
- [ ] 可以查看所有用戶的活動記錄
- [ ] 可以看到「活動概覽」等管理功能

#### 2.2 Agent 權限測試
```
測試用戶：dacagent@dacit.net / agent16011587
```
- [ ] 登入後檢查活動記錄中是否有登入記錄
- [ ] 在用戶篩選中只能看到自己
- [ ] 只能查看自己的活動記錄
- [ ] 無法看到其他用戶的活動

### 3. 活動記錄測試

#### 3.1 登入/登出記錄
- [ ] 用戶登入時自動記錄 `user_login` 活動
- [ ] 用戶登出時自動記錄 `user_logout` 活動
- [ ] 記錄包含 IP 位址和瀏覽器資訊

#### 3.2 對話管理記錄
- [ ] 進入對話管理頁面
- [ ] 指派對話給 Agent，檢查是否記錄 `conversation_assign` 活動
- [ ] 轉移對話給其他 Agent，檢查是否記錄 `conversation_transfer` 活動
- [ ] 關閉對話，檢查是否記錄 `conversation_close` 活動

#### 3.3 系統設定記錄
- [ ] 進入系統設定頁面
- [ ] 修改任何設定並保存
- [ ] 檢查是否記錄 `settings_update` 活動
- [ ] 活動詳情包含更新的設定項目

#### 3.4 團隊管理記錄
- [ ] 進入團隊管理頁面
- [ ] 邀請新成員，檢查是否記錄 `team_invite` 活動
- [ ] 更新成員角色，檢查是否記錄 `team_member_update` 活動
- [ ] 更新成員狀態，檢查是否記錄 `team_member_update` 活動

### 4. 篩選功能測試

#### 4.1 用戶篩選
- [ ] 選擇特定用戶，確認只顯示該用戶的活動
- [ ] 選擇「所有用戶」，確認顯示所有活動（僅 Admin）

#### 4.2 操作類型篩選
- [ ] 選擇「用戶登入」，確認只顯示登入記錄
- [ ] 選擇「對話指派」，確認只顯示對話指派記錄
- [ ] 選擇「系統設定更新」，確認只顯示設定更新記錄

#### 4.3 時間範圍篩選
- [ ] 選擇「今天」，確認只顯示今天的活動
- [ ] 選擇「最近一週」，確認顯示一週內的活動
- [ ] 選擇「自訂範圍」，設定特定時間範圍並測試

### 5. API 端點測試

#### 5.1 使用瀏覽器開發者工具
打開瀏覽器開發者工具 > Network 標籤

#### 5.2 測試 API 請求
- [ ] 載入活動記錄頁面，檢查 `GET /api/activities` 請求
- [ ] 應用篩選，檢查請求參數是否正確
- [ ] 切換頁面，檢查分頁參數是否正確
- [ ] 檢查回應狀態碼為 200
- [ ] 檢查回應資料格式正確

### 6. 錯誤處理測試

#### 6.1 未授權存取
- [ ] 登出後直接訪問 `/activities`，應該重定向到登入頁面
- [ ] 使用無效 Token 訪問 API，應該返回 401 錯誤

#### 6.2 權限不足
- [ ] Agent 嘗試查看其他用戶的活動，應該被拒絕
- [ ] Agent 嘗試訪問管理功能，應該被拒絕

## 🐛 常見問題排除

### 問題 1: 活動記錄頁面空白
**可能原因**: API 端點無法訪問
**檢查方法**: 
1. 開啟瀏覽器開發者工具 > Console
2. 查看是否有 JavaScript 錯誤
3. 檢查 Network 標籤中的 API 請求狀態

### 問題 2: 沒有活動記錄顯示
**可能原因**: 資料庫中沒有資料或權限問題
**檢查方法**:
1. 確認資料庫中有活動記錄
2. 檢查用戶權限設定
3. 查看 API 回應內容

### 問題 3: 篩選功能不工作
**可能原因**: 前端篩選邏輯或 API 參數問題
**檢查方法**:
1. 檢查 Network 標籤中的請求參數
2. 確認 API 端點正確處理篩選參數
3. 檢查前端篩選邏輯

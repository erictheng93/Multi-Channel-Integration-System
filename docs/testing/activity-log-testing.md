## 常見問題排除

### 問題 1: 活動記錄頁面空白
**可能原因**: API 端點無法訪問
**檢查方法**: 
1. 開啟瀏覽器開發者工具 > Console
2. 查看是否有 JavaScript 錯誤
3. 檢查 Network 標籤中的 API 請求狀態

### 問題 2: 沒有活動記錄顯示
**可能原因**: 資料庫中沒有資料或權限問題
**檢查方法**:
1. 確認資料庫中有活動記錄
2. 檢查用戶權限設定
3. 查看 API 回應內容

### 問題 3: 篩選功能不工作
**可能原因**: 前端篩選邏輯或 API 參數問題
**檢查方法**:
1. 檢查 Network 標籤中的請求參數
2. 確認 API 端點正確處理篩選參數
3. 檢查前端篩選邏輯

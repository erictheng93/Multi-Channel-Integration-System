# SystemSettings 語言設定診斷指南

## 概述

SystemSettings 頁面提供了完整的語言設定診斷和修復工具，幫助解決語言切換和保存失敗的問題。

## 診斷工具

### 1. 快速測試 (Quick Test)
- **用途**: 快速檢查基本功能是否正常
- **測試項目**:
  - API 連接測試
  - 基本語言切換測試
- **執行時間**: ~2-3 秒
- **適用場景**: 日常檢查、快速驗證

### 2. 完整診斷 (Full Diagnostic)
- **用途**: 深入分析所有可能的問題
- **檢查項目**:
  - 前端 i18n 狀態
  - 後端 API 連接
  - 設定讀取功能
  - 設定保存功能
  - 語言切換功能
  - 數據庫結構
  - 網路連接
- **執行時間**: ~10-15 秒
- **適用場景**: 問題排查、深度分析

### 3. 完整測試 (Complete Test)
- **用途**: 全面測試所有功能和性能
- **測試項目**:
  - 基礎連接測試
  - 設定讀寫測試
  - 語言切換測試
  - 錯誤處理測試
  - 性能測試
- **執行時間**: ~20-30 秒
- **適用場景**: 功能驗證、性能評估

## 修復工具

### 1. 快速修復 (Quick Fix)
- **用途**: 解決常見的語言設定問題
- **修復項目**:
  - 清理並重設 localStorage
  - 重設前端語言到預設值
  - 確保後端有預設設定
- **執行時間**: ~2-3 秒
- **適用場景**: 常見問題、快速解決

### 2. 深度修復 (Deep Fix)
- **用途**: 全面修復所有發現的問題
- **修復項目**:
  - 清理 localStorage
  - 初始化系統設定
  - 修復前後端同步
  - 測試語言切換
- **執行時間**: ~10-15 秒
- **適用場景**: 複雜問題、全面修復

## 使用流程

### 問題排查流程

1. **首次遇到問題**
   ```
   快速測試 → 如果失敗 → 快速修復 → 再次測試
   ```

2. **問題持續存在**
   ```
   完整診斷 → 分析結果 → 深度修復 → 完整測試
   ```

3. **驗證修復效果**
   ```
   測試所有語言 → 確認功能正常
   ```

### 診斷結果解讀

#### 成功率評級
- **90-100%**: 優秀 ✅ - 系統運行正常
- **70-89%**: 良好 ⚠️ - 有輕微問題，建議修復
- **50-69%**: 一般 ❌ - 有明顯問題，需要修復
- **<50%**: 較差 🚨 - 有嚴重問題，需要立即修復

#### 常見問題及解決方案

1. **API 連接失敗**
   - 檢查後端服務是否運行
   - 檢查網路連接
   - 檢查防火牆設定

2. **設定保存失敗**
   - 檢查數據庫權限
   - 檢查 system_settings 表結構
   - 檢查後端錯誤日誌

3. **語言切換失敗**
   - 清理 localStorage
   - 檢查語言包文件
   - 重新初始化 i18n

4. **前後端不同步**
   - 執行深度修復
   - 手動同步設定
   - 檢查 API 響應

## 開發模式功能

在開發模式下，SystemSettings 頁面會顯示額外的測試按鈕：

### 語言切換測試
- **測試繁中**: 直接切換到繁體中文
- **測試簡中**: 直接切換到簡體中文  
- **測試英文**: 直接切換到英文

### 診斷和修復
- **快速測試**: 執行基本功能測試
- **完整診斷**: 執行全面診斷分析
- **完整測試**: 執行完整測試套件
- **快速修復**: 執行快速問題修復
- **深度修復**: 執行全面問題修復
- **測試所有語言**: 測試所有支援的語言

## 控制台輸出

所有診斷和測試工具都會在瀏覽器控制台輸出詳細信息：

### 輸出格式
```
🔍 診斷類型
├── ✅ 成功項目: 描述
├── ⚠️ 警告項目: 描述
├── ❌ 失敗項目: 描述
└── 📊 統計摘要
```

### 查看控制台
1. 按 F12 打開開發者工具
2. 切換到 "Console" 標籤
3. 執行診斷或測試
4. 查看詳細輸出信息

## 故障排除

### 常見錯誤

1. **"儲存設定失敗"**
   - 執行完整診斷
   - 檢查後端 API 狀態
   - 執行深度修復

2. **語言切換無效果**
   - 清理瀏覽器緩存
   - 執行快速修復
   - 重新整理頁面

3. **前後端語言不一致**
   - 執行深度修復
   - 手動同步設定
   - 檢查 localStorage

### 緊急修復步驟

如果所有工具都無法解決問題：

1. **清理瀏覽器數據**
   ```javascript
   localStorage.clear()
   sessionStorage.clear()
   location.reload()
   ```

2. **重置系統設定**
   - 聯繫系統管理員
   - 重置數據庫設定表
   - 重新部署應用

3. **檢查後端日誌**
   - 查看 Cloudflare Workers 日誌
   - 檢查數據庫連接狀態
   - 驗證 API 端點配置

## 最佳實踐

1. **定期檢查**: 建議每週執行一次完整測試
2. **問題預防**: 遇到問題時立即執行診斷
3. **日誌記錄**: 保存診斷結果用於問題追蹤
4. **版本控制**: 記錄修復前後的系統狀態

## 技術細節

### 診斷工具架構
```
SystemSettingsDiagnostic
├── checkFrontendI18n()      # 前端 i18n 檢查
├── checkBackendAPI()        # 後端 API 檢查
├── testSettingsRead()       # 設定讀取測試
├── testSettingsSave()       # 設定保存測試
├── testLanguageSwitching()  # 語言切換測試
├── checkDatabaseStructure() # 數據庫結構檢查
└── checkNetworkConnectivity() # 網路連接檢查
```

### 修復工具架構
```
SystemSettingsFix
├── cleanLocalStorage()      # 清理 localStorage
├── initializeSystemSettings() # 初始化系統設定
├── fixFrontendBackendSync() # 修復前後端同步
└── testLanguageSwitchingAfterFix() # 修復後測試
```

### 測試工具架構
```
SystemSettingsTestSuite
├── testBasicConnectivity()  # 基礎連接測試
├── testSettingsReadWrite()  # 設定讀寫測試
├── testLanguageSwitching()  # 語言切換測試
├── testErrorHandling()      # 錯誤處理測試
└── testPerformance()        # 性能測試
```

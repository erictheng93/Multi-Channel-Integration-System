## 🔧 腳本功能說明

### `setup-env.ps1` - 開發環境設置腳本
**功能**:
- 自動生成 `.env` 檔案（後端環境變數）
- 自動生成 `frontend/.env.local`（前端環境變數）
- 自動生成 JWT Secret 和加密密鑰
- 建立配置指南 `ENV-SETUP-GUIDE.md`

**使用方式**:
```powershell
.\setup-env.ps1                    # 設置開發環境
.\setup-env.ps1 -Environment staging  # 設置測試環境
.\setup-env.ps1 -Force             # 強制覆蓋現有配置
```

### `quick-deploy.ps1` - 一鍵部署腳本
**功能**:
- 自動檢查所有必要工具
- 驗證 Cloudflare 登入狀態
- 建置前後端應用程式
- 部署到 Cloudflare 服務
- 初始化資料庫
- 顯示部署結果

**使用方式**:
```powershell
.\quick-deploy.ps1                 # 部署到生產環境
.\quick-deploy.ps1 -Environment staging  # 部署到測試環境
.\quick-deploy.ps1 -Help          # 查看所有選項
```

# 多渠道整合系統功能規格

**文件狀態**：Canonical truth source  
本文是本系統的完整功能規格。若 README、使用指南、API 參考或模組文件與本文不一致，應以本文為優先依據，直到本文被更新為止。

## 2. 產品摘要

多渠道整合系統是一套客服對話與團隊協作平台，提供統一收件匣、LINE/LIFF 整合、客服指派、團隊管理、標籤、客戶資料、檔案、通知、分析、稽核、監控、資料匯出與系統管理能力。

## 5. 核心功能規格

### 5.1 渠道整合

**目的**  
整合外部通訊渠道，特別是 LINE webhook 與訊息事件。

**功能**

- 接收 LINE webhook。
- 驗證 webhook 或渠道請求。
- 將外部訊息轉換為內部對話與訊息。
- 回覆或推播外部渠道訊息。
- 管理渠道設定。

### 5.2 系統

**目的**  
提供系統設定、路由、環境配置、維護與平台層能力。

**功能**

- 系統設定管理。
- 環境設定。
- 路由註冊與模組初始化。
- 錯誤處理。
- CORS 與 middleware。
- 部署與 Cloudflare runtime 設定。

### 5.3 客服人員

**目的**  
管理客服帳號、狀態、工作量與可用性。

**功能**

- 建立、查詢、更新、刪除客服人員。
- 取得單一客服與客服清單。
- 更新客服線上/離線/忙碌等狀態。
- 查詢可用客服。
- 查詢客服工作量。
- 前端提供客服列表、狀態、角色、團隊關聯與操作。

### 5.4 客戶

**目的**  
管理客戶資料、搜尋、對話關聯與客戶標籤。

**功能**

- 建立、查詢、更新、刪除客戶。
- 搜尋客戶。
- 批次建立、更新、刪除客戶。
- 取得客戶對話。
- 管理客戶標籤。
- 前端提供客戶清單、詳情、分群與操作。

### 5.5 團隊管理

**目的**  
管理客服團隊、團隊成員、團隊與客服的關聯，用於組織分工與對話分派。

**功能**

- 建立、讀取、更新、刪除團隊。
- 查詢團隊清單與單一團隊。
- 取得團隊成員。
- 新增與移除團隊成員。
- 取得客服所屬團隊。
- 設定與移除客服所屬團隊。
- 以 UI 管理團隊、成員數、狀態與操作。

### 5.6 LIFF

**目的**  
管理 LINE LIFF 設定並支援客戶端嵌入式體驗。

**功能**

- 取得 LIFF 設定。
- 更新 LIFF 設定。
- 驗證 LIFF 初始化與 profile。
- 提供 LIFF 前端所需的 channel 與 app 設定。

### 5.7 客戶端對話

**目的**  
提供客戶端或外部入口存取對話與訊息。

**功能**

- 建立或查詢客戶對話。
- 從客戶端傳送訊息。
- 查詢客戶端訊息清單。
- 支援 LIFF 或其他外部接入場景。

### 5.8 對話

**目的**  
提供統一對話收件匣、對話生命週期管理、客服指派與轉移。

**功能**

- 取得對話清單與單一對話。
- 建立、更新與刪除對話。
- 指派對話給客服。
- 將對話轉移給其他客服或團隊。
- 解除對話指派。
- 關閉對話。
- 批次更新對話。
- 搜尋對話。
- 依狀態、客服、客戶、標籤或其他條件篩選。

**指派與轉移規則**

- 指派會把對話分配給指定團隊。
- 轉移會將既有對話從目前團隊轉給另一個團隊。

### 5.9 訊息

**目的**  
提供訊息讀取、傳送、批次、搜尋、統計與匯出。

**功能**

- 取得訊息清單與單一訊息。
- 傳送文字與多媒體訊息。
- 依對話取得訊息。
- 批次建立、更新或刪除訊息。
- 搜尋訊息。
- 匯出訊息資料。
- 取得訊息統計。
- 支援訊息狀態與已讀/未讀流程。

### 5.10 佇列

**目的**  
處理非同步工作、批次工作、匯出、延遲訊息與背景任務。

**功能**

- 建立佇列任務。
- 處理任務。
- 重試失敗任務。
- 查詢任務狀態。
- 與延遲訊息、資料匯出、通知等功能整合。

### 5.11 即時事件

**目的**  
在系統內部與前端之間廣播狀態改變。

**功能**

- 新訊息事件。
- 對話更新事件。
- 指派與轉移事件。
- 客服狀態事件。
- 通知事件。
- 系統事件。

### 5.12 WebSocket

**目的**  
提供對話、訊息、客服狀態、typing 與系統事件的即時通訊。

**功能**

- 建立 WebSocket 連線。
- 訂閱對話或工作區事件。
- 發送與接收即時訊息事件。
- 發送 typing indicator。
- 更新 presence。
- 連線健康檢查與重連。

### 5.13 協作

**目的**  
支援客服間共同處理對話、內部協作與狀態同步。

**功能**

- 多客服查看同一對話。
- 內部協作事件。
- 指派、轉移、解除指派與關閉流程。
- 即時 presence 與 typing。
- 操作記錄可進入活動稽核。

**關聯模組**

- Conversations
- Agents
- Teams
- WebSocket
- Real-time Events
- Activity Audit

### 5.14 資料管理

**目的**  
集中管理資料匯出、匯入、備份、還原、清理與資料保留。

**功能**

- 取得資料匯出欄位。
- 建立匯出工作。
- 查詢匯出工作狀態。
- 下載匯出檔案。
- 匯入資料。
- 建立與還原備份。
- 清理資料。
- 取得資料統計。
- 管理資料保留設定。

**匯出範圍**

- 訊息資料可透過 messaging export 匯出。
- 資料管理模組提供較完整的匯出工作流程。
- 分析模組與活動稽核也有各自匯出入口，但其實作成熟度不同。

### 5.15 標籤

**目的**  
提供對話與客戶分類標記，支援顏色、描述與使用統計。

**功能**

- 建立、讀取、更新、刪除標籤。
- 搜尋標籤。
- 取得標籤使用統計。
- 依標籤取得相關對話。
- 依標籤取得相關客戶。
- 前端提供標籤列表、建立、編輯、刪除與顏色管理。

### 5.16 自動回覆

**目的**  
根據關鍵字、規則、時段或其他條件自動回覆客戶訊息。

**功能**

- 建立、讀取、更新、刪除自動回覆規則。
- 啟用或停用規則。
- 設定觸發條件、回覆內容與優先順序。
- 測試規則。
- 查詢規則統計。
- 管理自動回覆排程。
- 查詢自動回覆日誌。
- 前端提供規則列表、建立/編輯表單、啟用切換、排程與日誌視圖。

### 5.17 檔案管理

**目的**  
管理訊息附件與系統檔案，支援上傳、下載、預覽、刪除與中繼資料。

**功能**

- 上傳檔案。
- 取得檔案清單與單一檔案資訊。
- 下載或預覽檔案。
- 刪除檔案。
- 維護檔案 metadata、大小、類型與存放資訊。

### 5.18 通知

**目的**  
向使用者通知新訊息、指派、轉移、系統狀態或其他事件。

**功能**

- 取得通知清單。
- 建立通知。
- 標記單一通知已讀。
- 批次標記已讀。
- 刪除通知。
- 支援即時通知事件。

### 5.19 延遲訊息

**目的**  
排程未來送出的訊息並管理其生命週期。

**功能**

- 建立延遲訊息。
- 查詢延遲訊息清單與單筆。
- 更新排程內容。
- 取消延遲訊息。
- 立即處理到期訊息。
- 重試失敗的延遲訊息。
- 取得延遲訊息統計。
- 清理過期或完成資料。

### 5.20 分析

**目的**  
提供營運指標、客服績效、對話量、回覆時間與匯出。

**功能**

- 儀表板統計。
- 對話分析。
- 訊息分析。
- 客服績效。
- 趨勢與時間序列。
- 匯出分析資料。

**已知實作限制**

- 分析匯出路由存在，但目前產生的檔案 URL 可能仍為 stub，需在產品規格中標示成熟度。

### 5.21 報表

**目的**  
提供彙整型報表與管理檢視。

**功能**

- 產生營運報表。
- 查詢客服、對話、訊息與客戶相關報表。
- 支援篩選期間與維度。
- 可與分析與匯出功能串接。

### 5.22 監控

**目的**  
監控系統健康、效能、模組狀態與執行環境。

**功能**

- 健康檢查。
- 系統狀態頁。
- 模組狀態檢查。
- 效能與錯誤監控。
- 前端提供 system status 與 monitoring 頁面。

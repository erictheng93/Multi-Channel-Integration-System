## 1. 摘要

本系統是一套**生產級、企業級**的多渠道客服整合平台，將 LINE OA 與 Facebook Messenger 的客戶對話統一進單一介面，由客服團隊集中處理。

### 1.1 業務目標

- **統一通訊**：跨平台對話一站式管理
- **營運效率**：透過自動化降低回應時間、提升客服產能
- **可擴展架構**：支援企業級規模、含角色權限管理
- **數據洞察**：分析報表優化績效
- **成本優化**：自動化降低營運負擔

### 1.2 成功指標

| 指標 | 目標 |
|------|------|
| 系統可用性 | 99.9% |
| 訊息延遲 P95 | < 500ms |
| 併發 WebSocket 連線 | 1000+ |
| 部署時無停機 | 零停機部署 |

## 2. 業務情境

### 2.1 市場痛點

- **渠道碎片化**：客戶詢問散布在 LINE、Facebook、Email 等
- **服務品質不一致**：不同渠道回應時間差異大
- **營運效率低**：客服在多平台間切換
- **缺乏統一指標**：無跨渠道分析能力
- **規模化困難**：客戶量成長後人力跟不上

### 2.2 業務機會

亞太市場對 LINE / Facebook 整合需求強勁；中型企業逐漸需要專業客服工具；AI 與自動化需求快速擴張。

## 3. 功能需求（FR）摘要

### 3.1.1 多渠道整合
- 支援 LINE OA、Facebook Messenger
- 規劃中：Instagram、WhatsApp、Telegram
- 渠道憑證 AES-256-GCM 加密儲存
- 可擴展設計（JSON 設定欄位，加新平台不需改 schema）

### 3.1.2 角色權限管理（雙層角色）

採用「**系統角色 + 團隊角色**」雙層設計，取代 v3 的 3 層階層：

- **系統角色（2 種）**：
  - **Admin**：全系統管理權；跨團隊存取
  - **Agent**：客服人員，須透過團隊角色取得對話存取
- **團隊角色（3 種，每團隊獨立）**：
  - **Supervisor**：跨團隊監看、覆蓋指派
  - **Lead**：團隊主管，組內派遣與成員管理
  - **Member**：一般客服，處理被指派的對話
- **多團隊歸屬**：一位 Agent 可同時屬多團隊，每團隊角色可不同
- **JWT 內嵌**：`primaryTeamId`、`allowedTeamIds[]`、`teamRoles{}` 都在 token 裡，避免每次查 DB

> 完整權限矩陣見 [`RBAC_DESIGN.md`](../specifications/RBAC_DESIGN.md)。

### 3.1.3 對話管理

- **統一收件匣**：所有渠道對話於單一介面
- **僅團隊指派**：對話只指派給「團隊」（v4 移除個人指派），由 Lead/Supervisor 派發或成員自行領取
- **狀態追蹤**：pending → in-progress → waiting → resolved
- **跨團隊轉移**：完整歷史紀錄（`conversationTransfers` 表）

### 3.1.4 延遲訊息系統

- 1-120 秒可調延遲
- 即時撤回（< 100ms，DO Alarm 排程，非 KV 輪詢）
- 完整稽核日誌

### 3.1.5 檔案管理

- 多格式支援（圖、影音、PDF、DOC）
- Cloudflare R2 全球 CDN
- Presigned URL（預設 1 小時）
- 自動縮圖、EXIF 隱私清理

### 3.1.6 即時通訊

- WebSocket + Durable Objects（v4 取代 v3 的 SSE）
- 1000+ 併發連線
- 多分頁同步、自動重連
- 即時打字 / 線上狀態廣播

### 3.1.7 自動回覆

- 規則引擎（關鍵字、regex、營業時間、welcome）
- AND / OR 條件、動作鏈
- 全域與團隊範圍規則並存

### 3.1.8 報表與分析

- Analytics 即時指標
- Reports 20+ 報表類型（CSV / Excel / PDF / HTML）
- 排程 Email 寄送

### 3.1.9 稽核日誌

- 所有動作（建立 / 更新 / 刪除 / 登入）自動寫入
- 角色可見性（admin 看全部、agent 看自己）

## 4. 非功能需求（NFR）摘要

| 類別 | 要求 |
|------|------|
| 效能 | API 回應 P95 < 200ms；WebSocket 延遲 P95 < 500ms |
| 規模 | 1000+ 併發 WebSocket 連線；100+ 訊息 / 秒 |
| 可用性 | 99.9% SLA |
| 安全 | JWT 雙令牌、AES-256-GCM 加密、HMAC 簽章驗證 |
| 合規 | 完整稽核日誌、軟刪除保留歷史 |
| 部署 | 零停機部署、自動回滾 |

## 5. 主要利害關係人

| 角色 | 系統內身分 | 關注重點 |
|------|-----------|---------|
| 客服團隊 | Agent + Member | UI 易用度、訊息延遲 |
| 客服主管 | Agent + Lead | 派遣效率、團隊統計 |
| 副主管 / 督導 | Agent + Supervisor | 跨組監看、覆蓋指派 |
| IT 主管 / 客服中心總監 | Admin | 系統穩定、整合擴展、合規 |
| 業務決策者 | （查報表） | ROI、效能指標、商業洞察 |

| 面向 | v3 | v4 |
|------|----|----|
| 即時通訊 | SSE + KV 輪詢 | WebSocket + DO |
| 系統角色 | 3 層 | 2 層 |
| 對話指派 | 個人 + 團隊 | 僅團隊 |
| 多團隊歸屬 | 受限 | 完整支援 |
| 訊息延遲 P95 | ~2s | < 500ms |


## 📊 降級場景測試

### 場景 1: WebSocket 初始化失敗

```
觸發: Durable Objects 初始化拋出異常

處理流程:
1. 嘗試初始化 WebSocket 適配器
   ↓ [失敗]
2. 捕獲錯誤並記錄日誌
   ↓
3. WebSocket 適配器未註冊
   ↓
4. 檢測預設協議 (websocket) 不可用
   ↓
5. 自動切換到 SSE 作為預設協議
   ↓
6. ✅ 系統正常運行 (SSE 模式)

日誌:
❌ Failed to initialize WebSocket adapter: [error]
⚠️  WebSocket not available, falling back to SSE as default
✅ Collaboration Module initialized in SSE fallback mode
```

### 場景 2: 運行時 WebSocket 請求失敗

```
觸發: 前端請求使用 WebSocket 但適配器不可用

POST /api/collaboration/conversations/123/join
Body: { "protocol": "websocket" }

處理流程:
1. 接收請求指定 protocol = "websocket"
   ↓
2. 調用 getAdapter('websocket')
   ↓
3. 檢測 WebSocket 適配器不存在
   ↓
4. 自動返回 SSE 適配器
   ↓
5. ✅ 請求成功處理 (使用 SSE)

日誌:
⚠️ [CollaborationManager] WebSocket not available, falling back to SSE
✅ Joined conversation successfully (using SSE)
```

### 場景 3: 完全初始化失敗

```
觸發: 主初始化和降級初始化都失敗

處理流程:
1. 嘗試主初始化 (WebSocket + SSE)
   ↓ [失敗]
2. 捕獲錯誤，嘗試降級初始化 (SSE only)
   ↓ [失敗]
3. ❌ 拋出錯誤，協作功能不可用
   ↓
4. ⚠️ 主應用繼續運行（協作功能禁用）

日誌:
❌ Failed to initialize Collaboration Module: [error]
⚠️ Attempting fallback to SSE-only mode...
❌ Fallback initialization also failed: [error]
⚠️ Collaboration module initialization failed (continuing anyway)
```

## 💰 成本估算

### 當前配置成本 (生產環境 WebSocket 優先)

```
假設: 1000 活躍用戶，平均每天 10 次協作互動

Cloudflare Workers 成本:
├─ Workers 基礎費用: $5.00/月
├─ Durable Objects 請求: 300,000 × $0.15/百萬 = $0.045/月
├─ WebSocket 訊息: ~3,000,000 × $12.50/百萬 = $37.50/月
└─ 總計: ~$42.55/月

SSE only 成本 (對比):
├─ Workers 基礎費用: $5.00/月
├─ 超額請求費用: ~$0.15/月
└─ 總計: ~$5.15/月

成本差異: WebSocket 約貴 $37/月 (8 倍)

評估建議:
├─ 用戶 < 500 人: 考慮 SSE only
├─ 用戶 500-2000 人: WebSocket 性價比高
└─ 用戶 > 2000 人: WebSocket 必選
```

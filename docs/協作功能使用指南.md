## 功能概述

### 什麼是協作功能？

協作功能讓多位客服人員能夠：
- ✅ **同時查看**同一個對話，看到其他客服正在處理
- ✅ **即時看到**其他客服正在輸入（Typing Indicator）
- ✅ **追蹤狀態**查看客服的在線/離線/忙碌狀態
- ✅ **避免衝突**知道誰正在回覆，避免重複處理

## 快速開始

### 第一步：了解系統架構

```
使用者（前端） → REST API → Collaboration 模組 → SSE/WebSocket
     ↓              ↓              ↓                  ↓
  發起請求      統一接口     協議適配器         即時推送
```

### 第二步：基本流程

```typescript
// 1️⃣ 客服打開對話頁面
// 前端自動調用: POST /api/collaboration/conversations/:id/join

// 2️⃣ 系統記錄客服正在查看
// 響應: { success: true, message: "Joined conversation successfully" }

// 3️⃣ 客服開始輸入
// 前端調用: POST /api/collaboration/typing
// 參數: { conversationId: 123, status: "start" }

// 4️⃣ 其他客服即時看到 "XXX 正在輸入..."
// 透過 SSE 推送: { type: "typing_start", userId: 1, ... }

// 5️⃣ 客服離開對話
// 前端調用: POST /api/collaboration/conversations/:id/leave
```

### 第三步：前端初始化範例

```typescript
// composables/useCollaboration.ts
import { ref, onMounted, onUnmounted } from 'vue';

export function useCollaboration(conversationId: number) {
  const viewers = ref([]);
  const typingUsers = ref([]);

  // 加入對話
  const joinConversation = async () => {
    const response = await fetch(
      `/api/collaboration/conversations/${conversationId}/join`,
      {
        method: 'POST',
        headers: {
          'Authorization': `Bearer ${token}`,
          'Content-Type': 'application/json'
        }
      }
    );

    if (response.ok) {
      console.log('✅ 成功加入對話協作');
    }
  };

  // 離開對話
  const leaveConversation = async () => {
    await fetch(
      `/api/collaboration/conversations/${conversationId}/leave`,
      { method: 'POST', headers: { 'Authorization': `Bearer ${token}` } }
    );
  };

  // 發送輸入狀態
  const sendTyping = async (isTyping: boolean) => {
    await fetch('/api/collaboration/typing', {
      method: 'POST',
      headers: {
        'Authorization': `Bearer ${token}`,
        'Content-Type': 'application/json'
      },
      body: JSON.stringify({
        conversationId,
        status: isTyping ? 'start' : 'stop'
      })
    });
  };

  onMounted(() => {
    joinConversation();
  });

  onUnmounted(() => {
    leaveConversation();
  });

  return { viewers, typingUsers, sendTyping };
}
```

### 2. 輸入狀態指示器（Typing Indicator）

#### 功能說明
當客服正在輸入時，其他查看同一對話的客服會看到 "XXX 正在輸入..." 提示。

#### 前端實現

**方法 1: 輸入框監聽**
```typescript
import { ref, watch } from 'vue';
import { debounce } from 'lodash-es';

const messageInput = ref('');
let typingTimeout: NodeJS.Timeout;

// 防抖發送 typing start
const sendTypingStart = debounce(() => {
  fetch('/api/collaboration/typing', {
    method: 'POST',
    headers: {
      'Authorization': `Bearer ${token}`,
      'Content-Type': 'application/json'
    },
    body: JSON.stringify({
      conversationId: currentConversationId.value,
      status: 'start'
    })
  });
}, 300);

// 監聽輸入
watch(messageInput, (newValue, oldValue) => {
  if (newValue && !oldValue) {
    // 開始輸入
    sendTypingStart();
  }

  // 清除舊的 timeout
  clearTimeout(typingTimeout);

  // 5 秒後自動發送 stop
  typingTimeout = setTimeout(() => {
    fetch('/api/collaboration/typing', {
      method: 'POST',
      headers: {
        'Authorization': `Bearer ${token}`,
        'Content-Type': 'application/json'
      },
      body: JSON.stringify({
        conversationId: currentConversationId.value,
        status: 'stop'
      })
    });
  }, 5000);
});
```

**方法 2: 發送訊息時自動停止**
```typescript
const sendMessage = async (content: string) => {
  // 1. 停止輸入狀態
  await fetch('/api/collaboration/typing', {
    method: 'POST',
    headers: {
      'Authorization': `Bearer ${token}`,
      'Content-Type': 'application/json'
    },
    body: JSON.stringify({
      conversationId: currentConversationId.value,
      status: 'stop'
    })
  });

  // 2. 發送訊息
  await fetch('/api/messages', {
    method: 'POST',
    body: JSON.stringify({ conversationId, content })
  });

  // 3. 清空輸入框
  messageInput.value = '';
};
```

#### 功能說明

  | 'online'   // 在線（綠色）

#### 自動暫離檢測

```typescript
// composables/useAutoAway.ts
import { onMounted, onUnmounted } from 'vue';

export function useAutoAway() {
  let idleTimer: NodeJS.Timeout;
  const IDLE_TIMEOUT = 5 * 60 * 1000; // 5 分鐘

  const resetIdleTimer = () => {
    clearTimeout(idleTimer);

    // 設置為在線
    fetch('/api/collaboration/presence', {
      method: 'POST',
      headers: {
        'Authorization': `Bearer ${token}`,
        'Content-Type': 'application/json'
      },
      body: JSON.stringify({ status: 'online' })
    });

    // 5 分鐘後自動暫離
    idleTimer = setTimeout(() => {
      fetch('/api/collaboration/presence', {
        method: 'POST',
        headers: {
          'Authorization': `Bearer ${token}`,
          'Content-Type': 'application/json'
        },
        body: JSON.stringify({ status: 'away' })
      });
    }, IDLE_TIMEOUT);
  };

  onMounted(() => {
    // 監聽用戶活動
    window.addEventListener('mousemove', resetIdleTimer);
    window.addEventListener('keydown', resetIdleTimer);
    window.addEventListener('click', resetIdleTimer);

    resetIdleTimer();
  });

  onUnmounted(() => {
    clearTimeout(idleTimer);
    window.removeEventListener('mousemove', resetIdleTimer);
    window.removeEventListener('keydown', resetIdleTimer);
    window.removeEventListener('click', resetIdleTimer);
  });
}
```

## 前端整合指南

### 完整的 Vue 3 組合式函數

```typescript
// composables/useCollaboration.ts
import { ref, computed, onMounted, onUnmounted, watch } from 'vue';
import { useAuthStore } from '@/stores/auth';
import { debounce } from 'lodash-es';

export interface CollaborationOptions {
  conversationId: number;
  autoJoin?: boolean;
  autoLeave?: boolean;
  enableTyping?: boolean;
  enablePresence?: boolean;
}

export function useCollaboration(options: CollaborationOptions) {
  const authStore = useAuthStore();
  const token = computed(() => authStore.token);

  // 狀態
  const viewers = ref<Viewer[]>([]);
  const typingUsers = ref<TypingUser[]>([]);
  const isJoined = ref(false);
  const isTyping = ref(false);

  // API 基礎 URL
  const API_BASE = '/api/collaboration';

  // ==================== 核心方法 ====================

  /**
   * 加入對話
   */
  const joinConversation = async () => {
    if (isJoined.value) return;

    try {
      const response = await fetch(
        `${API_BASE}/conversations/${options.conversationId}/join`,
        {
          method: 'POST',
          headers: {
            'Authorization': `Bearer ${token.value}`,
            'Content-Type': 'application/json'
          }
        }
      );

      if (response.ok) {
        isJoined.value = true;
        console.log('✅ 成功加入對話協作');

        // 加入後立即獲取狀態
        await refreshState();
      }
    } catch (error) {
      console.error('❌ 加入對話失敗:', error);
    }
  };

  /**
   * 離開對話
   */
  const leaveConversation = async () => {
    if (!isJoined.value) return;

    try {
      await fetch(
        `${API_BASE}/conversations/${options.conversationId}/leave`,
        {
          method: 'POST',
          headers: {
            'Authorization': `Bearer ${token.value}`
          }
        }
      );

      isJoined.value = false;
      console.log('✅ 成功離開對話協作');
    } catch (error) {
      console.error('❌ 離開對話失敗:', error);
    }
  };

  /**
   * 發送輸入狀態
   */
  const sendTypingStatus = async (status: 'start' | 'stop') => {
    if (!options.enableTyping) return;

    try {
      await fetch(`${API_BASE}/typing`, {
        method: 'POST',
        headers: {
          'Authorization': `Bearer ${token.value}`,
          'Content-Type': 'application/json'
        },
        body: JSON.stringify({
          conversationId: options.conversationId,
          status
        })
      });

      isTyping.value = status === 'start';
    } catch (error) {
      console.error('❌ 發送輸入狀態失敗:', error);
    }
  };

  /**
   * 開始輸入（防抖）
   */
  const startTyping = debounce(() => {
    sendTypingStatus('start');
  }, 300);

  /**
   * 停止輸入
   */
  const stopTyping = () => {
    sendTypingStatus('stop');
  };

  /**
   * 更新在線狀態
   */
  const updatePresence = async (status: 'online' | 'away' | 'busy' | 'offline') => {
    if (!options.enablePresence) return;

    try {
      await fetch(`${API_BASE}/presence`, {
        method: 'POST',
        headers: {
          'Authorization': `Bearer ${token.value}`,
          'Content-Type': 'application/json'
        },
        body: JSON.stringify({
          status,
          currentConversation: status !== 'offline' ? options.conversationId : undefined
        })
      });
    } catch (error) {
      console.error('❌ 更新在線狀態失敗:', error);
    }
  };

  /**
   * 刷新對話狀態
   */
  const refreshState = async () => {
    try {
      const response = await fetch(
        `${API_BASE}/conversations/${options.conversationId}/state`,
        {
          headers: {
            'Authorization': `Bearer ${token.value}`
          }
        }
      );

      if (response.ok) {
        const data = await response.json();
        viewers.value = data.data.viewers;
        typingUsers.value = data.data.typing.map((t: any) => ({
          userId: t.userId,
          displayName: viewers.value.find(v => v.userId === t.userId)?.displayName || 'Unknown'
        }));
      }
    } catch (error) {
      console.error('❌ 刷新狀態失敗:', error);
    }
  };

  // ==================== 計算屬性 ====================

  /**
   * 其他查看者（排除自己）
   */
  const otherViewers = computed(() => {
    const currentUserId = authStore.user?.userId;
    return viewers.value.filter(v => v.userId !== currentUserId);
  });

  /**
   * 輸入提示文字
   */
  const typingText = computed(() => {
    const count = typingUsers.value.length;
    if (count === 0) return '';
    if (count === 1) return `${typingUsers.value[0].displayName} 正在輸入...`;
    if (count === 2) {
      return `${typingUsers.value[0].displayName} 和 ${typingUsers.value[1].displayName} 正在輸入...`;
    }
    return `${typingUsers.value[0].displayName} 和其他 ${count - 1} 人正在輸入...`;
  });

  // ==================== 生命週期 ====================

  let refreshInterval: NodeJS.Timeout;

  onMounted(async () => {
    // 自動加入
    if (options.autoJoin !== false) {
      await joinConversation();
    }

    // 設置在線
    if (options.enablePresence !== false) {
      await updatePresence('online');
    }

    // 定期刷新狀態（5 秒）
    refreshInterval = setInterval(() => {
      if (isJoined.value) {
        refreshState();
      }
    }, 5000);
  });

  onUnmounted(async () => {
    clearInterval(refreshInterval);

    // 停止輸入
    if (isTyping.value) {
      await stopTyping();
    }

    // 自動離開
    if (options.autoLeave !== false) {
      await leaveConversation();
    }
  });

  // ==================== 返回 ====================

  return {
    // 狀態
    viewers,
    typingUsers,
    isJoined,
    isTyping,

    // 計算屬性
    otherViewers,
    typingText,

    // 方法
    joinConversation,
    leaveConversation,
    startTyping,
    stopTyping,
    updatePresence,
    refreshState
  };
}
```

## 配置說明

### 系統配置

協作模組在 `src/index.ts` 中初始化，配置如下：

```typescript
await Collaboration.initialize(env, {
  // 預設使用的協議
  defaultProtocol: 'sse',

  // 是否啟用 WebSocket（預設關閉）
  enableWebSocket: false,

  // 輸入狀態過期時間（秒）
  typingExpirationSeconds: 5,

  // 在線狀態過期時間（秒）
  presenceExpirationSeconds: 300,

  // 清理任務執行間隔（秒）
  cleanupIntervalSeconds: 60,

  // 每個對話最大查看者數
  maxViewersPerConversation: 50,

  // 是否記錄協作事件到資料庫
  persistEvents: false
});
```

### 配置項說明

| 配置項 | 類型 | 預設值 | 說明 |
|--------|------|--------|------|
| `defaultProtocol` | `'sse' \| 'websocket' \| 'http'` | `'sse'` | 預設協議 |
| `enableWebSocket` | `boolean` | `false` | 是否啟用 WebSocket |
| `typingExpirationSeconds` | `number` | `5` | 輸入狀態自動過期時間 |
| `presenceExpirationSeconds` | `number` | `300` | 在線狀態自動過期時間 |
| `cleanupIntervalSeconds` | `number` | `60` | 清理任務執行頻率 |
| `maxViewersPerConversation` | `number` | `50` | 單對話最大查看者數 |
| `persistEvents` | `boolean` | `false` | 是否持久化事件 |

### 啟用 WebSocket

如需啟用 WebSocket 支援（需要 Durable Objects）：

```typescript
// src/index.ts
await Collaboration.initialize(env, {
  defaultProtocol: 'websocket',  // 切換為 WebSocket
  enableWebSocket: true,          // 啟用 WebSocket
  // ... 其他配置保持不變
});
```

**注意事項**:
- WebSocket 需要 Cloudflare Workers 付費方案
- 確保 `wrangler.toml` 中已配置 Durable Objects
- WebSocket 性能更好但成本較高，根據需求選擇

## 常見問題

### Q1: 為什麼其他客服看不到我的輸入狀態？

**可能原因**:
1. 沒有調用 `POST /api/collaboration/typing` API
2. 輸入狀態已過期（5 秒自動過期）
3. 其他客服沒有加入同一對話
4. 前端沒有正確處理 SSE 事件

**解決方法**:
```typescript
// 確保正確發送輸入狀態
const handleInput = () => {
  startTyping(); // 這會調用 API

  // 5 秒後自動停止
  clearTimeout(typingTimeout);
  typingTimeout = setTimeout(stopTyping, 5000);
};
```

### Q3: 客服關閉瀏覽器後多久會被移除？

**自動清理機制**:
- **正常離開**: 調用 `/leave` 端點立即移除
- **異常關閉**: 5 分鐘（300 秒）後自動清理
- **切換對話**: 加入新對話時自動離開舊對話

**建議做法**:
```typescript

  );

```

### Q4: SSE 和 WebSocket 有什麼區別？

| 特性 | SSE | WebSocket |
|------|-----|-----------|
| **連接方式** | HTTP | 升級協議 |
| **數據方向** | 單向（服務器→客戶端） | 雙向 |
| **自動重連** | ✅ 瀏覽器自動 | ❌ 需手動實現 |
| **開銷** | 較低 | 較高 |
| **成本** | 免費 | 需付費方案 |
| **適用場景** | 實時通知、狀態更新 | 聊天、遊戲 |

**推薦**:
- 大多數情況使用 **SSE**（預設）
- 需要客戶端發起大量消息時考慮 **WebSocket**

### Q5: 如何實現自動暫離功能？

```typescript
// composables/useAutoAway.ts
export function useAutoAway() {
  const IDLE_TIMEOUT = 5 * 60 * 1000; // 5 分鐘
  let idleTimer: NodeJS.Timeout;

  const resetTimer = () => {
    clearTimeout(idleTimer);

    // 設置為在線
    updatePresence('online');

    // 5 分鐘後自動暫離
    idleTimer = setTimeout(() => {
      updatePresence('away');
    }, IDLE_TIMEOUT);
  };

  // 監聽用戶活動
  onMounted(() => {
    ['mousemove', 'keydown', 'click', 'scroll'].forEach(event => {
      window.addEventListener(event, resetTimer);
    });
    resetTimer();
  });

  onUnmounted(() => {
    clearTimeout(idleTimer);
    ['mousemove', 'keydown', 'click', 'scroll'].forEach(event => {
      window.removeEventListener(event, resetTimer);
    });
  });
}
```

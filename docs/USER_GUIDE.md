# 用戶使用指南

## 快速開始

歡迎使用 Multi-Channel Customer Support System v3.0！這是一個企業級的多渠道客服管理系統，支援 LINE OA、Facebook Messenger 等平台的統一管理。

### 系統要求

- 現代瀏覽器 (Chrome 90+, Firefox 88+, Safari 14+, Edge 90+)
- 網路連接 (建議寬頻連接以獲得最佳體驗)
- JavaScript 啟用

## 登入系統

### 首次登入

1. 開啟瀏覽器並訪問系統網址
2. 輸入管理員提供的帳號和密碼
3. 點擊「登入」按鈕
4. 系統會自動引導您到儀表板

### 忘記密碼

請聯繫系統管理員重設密碼。

## 主要功能介紹

### 📊 儀表板

儀表板是系統的主頁，提供：
- **系統概覽**: 即時統計數據
- **活動摘要**: 最近的對話和活動
- **快速操作**: 常用功能的快速入口
- **通知中心**: 重要訊息和提醒

### 💬 對話管理

#### 查看對話
1. 點擊左側選單的「對話」
2. 選擇要查看的對話
3. 在右側面板查看完整的對話記錄

#### 回覆客戶
1. 在對話面板中找到輸入框
2. 輸入回覆內容
3. 可以選擇：
   - **立即發送**: 點擊「發送」按鈕
   - **延遲發送**: 設定 1-120 秒的延遲時間
4. 在延遲期間可以撤回訊息

#### 指派對話
1. 點擊對話右上角的「指派」按鈕
2. 選擇要指派的團隊成員
3. 確認指派

#### 轉移對話
1. 點擊對話右上角的「轉移」按鈕
2. 選擇目標團隊
3. 填寫轉移原因（可選）
4. 確認轉移

### 👥 團隊管理

#### 查看團隊
1. 點擊左側選單的「團隊管理」
2. 查看所有團隊列表
3. 點擊團隊名稱查看詳細資訊

#### 管理團隊成員
1. 進入團隊詳情頁
2. 在「成員」區域可以：
   - 查看現有成員
   - 新增成員
   - 修改成員角色
   - 移除成員

### 👤 客戶管理

#### 查看客戶資料
1. 點擊左側選單的「客戶」
2. 瀏覽客戶列表
3. 點擊客戶名稱查看詳細資料

#### 編輯客戶資訊
1. 在客戶詳情頁點擊「編輯」
2. 修改必要資訊
3. 點擊「儲存」確認更改

### 📱 QR Code 管理

#### 生成 QR Code
1. 點擊左側選單的「QR Code」
2. 點擊「新建 QR Code」
3. 設定：
   - 名稱和描述
   - 指派的團隊
   - 有效期限（可選）
   - 使用次數限制（可選）
4. 點擊「生成」

#### 使用 QR Code
- 客戶掃描 QR Code 後會自動指派到指定團隊
- 可以在「使用統計」中查看掃描記錄

### 📈 API 監控 (新功能)

#### 查看 API 狀態
1. 點擊左側選單的「API 監控」
2. 查看即時的 API 狀態統計
3. 系統每 15 秒自動更新

#### 詳細診斷
1. 點擊任意統計卡片
2. 在彈出視窗中查看：
   - 具體的 API 端點
   - 回應時間
   - 錯誤原因

#### 手動刷新
- 點擊右上角的「手動刷新」按鈕立即更新狀態

## 用戶角色說明

### 👨‍💼 管理員 (Admin)
- **權限**: 系統所有功能的完整存取權
- **功能**:
  - 管理所有團隊和用戶
  - 查看系統設定和監控
  - 存取所有對話和數據
  - 管理平台整合設定

### 👨‍💻 團隊領導 (Team)
- **權限**: 管理指派團隊的完整權限
- **功能**:
  - 管理團隊成員
  - 查看團隊對話和統計
  - 指派和轉移對話
  - 管理團隊 QR Code

### 🎧 客服人員 (Agent)
- **權限**: 處理指派的客戶對話
- **功能**:
  - 回覆指派的對話
  - 查看客戶資料
  - 使用延遲發送功能
  - 參與團隊協作

## 進階功能

### 🔄 即時協作

#### 多人協作
- 多個客服人員可以同時查看同一對話
- 即時顯示其他人的打字狀態
- 避免重複回覆的衝突

#### 狀態提示
- **打字中**: 顯示誰正在輸入
- **在線狀態**: 顯示團隊成員是否在線
- **最後活動**: 顯示最後活動時間

### ⏰ 延遲發送

#### 設定延遲
1. 在訊息輸入框下方找到延遲設定
2. 選擇 1-120 秒的延遲時間
3. 點擊「延遲發送」

#### 撤回訊息
1. 在延遲期間，訊息會顯示倒數計時
2. 點擊「撤回」按鈕可以取消發送
3. 撤回後可以重新編輯訊息

### 📊 數據統計

#### 個人統計
- 查看個人的對話處理數量
- 平均回應時間
- 客戶滿意度評分

#### 團隊統計
- 團隊整體效能
- 對話分配情況
- 工作負載分析

## 常見問題

### Q: 為什麼有些功能我看不到？
A: 功能的可見性取決於您的用戶角色。請聯繫管理員確認您的權限設定。

### Q: 如何更改我的個人資訊？
A: 點擊右上角的用戶名稱，選擇「個人設定」進行修改。

### Q: 延遲發送的訊息可以撤回多久？
A: 可以設定 1-120 秒的延遲時間，在這個時間內都可以撤回訊息。

### Q: 如何知道客戶是否已讀我的訊息？
A: 已讀狀態會根據不同的平台顯示（如 LINE 的已讀標記）。

### Q: API 監控顯示錯誤怎麼辦？
A: 請聯繫技術人員檢查系統狀態，或查看 API 監控的詳細錯誤資訊。

## 最佳實踐

### 💡 對話處理
- **及時回應**: 盡量在 5 分鐘內回覆客戶
- **使用範本**: 對於常見問題，使用預設的回覆範本
- **詳細記錄**: 在對話中記錄重要的客戶需求
- **適當指派**: 將專業問題指派給專業人員

### 👥 團隊協作
- **狀態更新**: 及時更新您的在線狀態
- **避免衝突**: 查看其他人是否正在處理同一對話
- **知識分享**: 與團隊分享處理複雜問題的經驗

### 📱 移動設備使用
- **響應式設計**: 系統支援手機和平板訪問
- **觸控操作**: 大部分功能都針對觸控設備進行了優化
- **離線提醒**: 在網路不穩定時會有相應提示

### 🔒 安全注意事項
- **定期登出**: 在公共設備上使用後務必登出
- **密碼安全**: 使用強密碼並定期更換
- **資料保護**: 不要在非安全網路下處理敏感客戶資料

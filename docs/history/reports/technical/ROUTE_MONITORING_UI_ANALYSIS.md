### 方案 C: 保持 CLI 為主，輕量級 API 輔助（最推薦）

#### 架構設計

```
CLI 工具 (主力):
$ npm run check:routes
  ↓
快速、即時、零成本

API 端點 (輔助):
GET /api/debug/routes/check
  ↓
返回 JSON 格式結果
供前端可選性展示
```

#### 實現方式

```typescript
// src/handlers/debug-routes.ts (新增 50 行代碼)

import { Hono } from 'hono';
import { jwtAuth, requireAdmin } from '@/middleware/auth';

const debugRouter = new Hono();

// 路由檢測 API (僅限 Admin)
debugRouter.get('/routes/check', jwtAuth, requireAdmin(), async (c) => {
  // 1. 執行檢測邏輯 (復用現有 detect-route-conflicts.ts)
  const { routes, conflicts } = await detectRouteConflicts();

  // 2. 返回 JSON 格式
  return c.json({
    success: true,
    data: {
      totalRoutes: routes.length,
      totalConflicts: conflicts.length,
      conflicts: conflicts.map(c => ({
        severity: c.severity,
        route1: { path: c.route1.path, location: `${c.route1.file}:${c.route1.line}` },
        route2: { path: c.route2.path, location: `${c.route2.file}:${c.route2.line}` },
        suggestion: c.suggestion
      }))
    },
    timestamp: new Date().toISOString()
  });
});

export default debugRouter;
```

#### 前端整合（可選）

```vue
<!-- frontend/src/views/ApiMonitor.vue -->
<template>
  <div class="api-monitor">
    <!-- 現有監控功能 -->

    <!-- 新增：路由健康檢查區塊 -->
    <div class="route-health-section">
      <h3> 路由健康檢查</h3>
      <button @click="checkRoutes">運行檢測</button>

      <div v-if="routeConflicts" class="conflicts-list">
        <div v-for="conflict in routeConflicts" :key="conflict.id">
          <span :class="`severity-${conflict.severity}`">
            {{ conflict.severity }}
          </span>
          {{ conflict.route1.path }}  {{ conflict.route2.path }}
        </div>
      </div>
    </div>
  </div>
</template>

<script setup>
const checkRoutes = async () => {
  const response = await fetch('/api/debug/routes/check');
  const data = await response.json();
  routeConflicts.value = data.data.conflicts;
};
</script>
```

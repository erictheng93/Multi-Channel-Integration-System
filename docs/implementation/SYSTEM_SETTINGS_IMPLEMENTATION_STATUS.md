## 🚀 使用說明

### 管理員使用
1. 透過側邊導航進入系統設定
2. 使用分頁介面切換不同設定類別：
   - **一般設定**: 系統名稱、聯絡信箱、時區、語言
   - **平台整合**: LINE OA 和 Facebook Messenger 設定
   - **進階設定**: 效能和功能開關
   - **系統管理**: 資料庫管理和系統控制

### 開發者使用
1. 組件完全自包含，包含所有必要樣式
2. API 整合透過現有的 `systemApi` 客戶端處理
3. 所有表單都包含適當的驗證和錯誤處理
4. 組件遵循應用程式既定的設計模式

## 📋 設定選項

### 一般設定
- 系統名稱
- 聯絡信箱
- 時區選擇
- 語言偏好

### 平台整合
- **LINE Official Account**:
  - Channel ID
  - Channel Secret
  - Access Token
  - 連線測試
- **Facebook Messenger**:
  - App ID
  - App Secret
  - Page ID
  - Page Token
  - 連線測試

- 系統日誌開關
- 效能監控開關

### 系統管理
- 資料庫備份/還原
- 快取管理
- 健康檢查
- 系統重啟

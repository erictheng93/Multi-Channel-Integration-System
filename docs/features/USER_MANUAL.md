## 系統概述

多渠道客服系統是一個統一管理 LINE 和 Facebook Messenger 客戶訊息的現代化平台。透過這個系統，客服人員可以在單一介面中處理來自不同平台的客戶對話，提升工作效率並確保服務品質。

## 登入系統

### 首次登入

1. **開啟系統網址**
   - 在瀏覽器中輸入系統網址
   - 系統會自動導向登入頁面

2. **輸入登入資訊**
   ```
   電子郵件：your-email@company.com
   密碼：your-password
   ```

3. **點擊「登入」按鈕**
   - 系統會驗證您的身份
   - 登入成功後會導向主控台

### 忘記密碼

如果忘記密碼，請聯繫系統管理員重設密碼。

### 登出系統

點擊右上角的用戶名稱，選擇「登出」即可安全登出系統。

## 對話管理

### 對話列表

對話列表顯示所有客戶對話，包含以下資訊：

- **客戶名稱** - 顯示客戶的姓名或暱稱
- **最後訊息** - 最新一則訊息的內容預覽
- **時間** - 最後訊息的時間
- **狀態** - 對話的處理狀態
- **平台** - 訊息來源平台（LINE/Facebook）
- **負責人** - 目前處理的客服人員

### 對話狀態說明

| 狀態 | 說明 | 顏色標示 |
|------|------|----------|
| 待處理 | 新的客戶訊息，尚未指派 | 🔴 紅色 |
| 處理中 | 已指派給客服人員處理 | 🟡 黃色 |
| 已結束 | 對話已完成並關閉 | 🟢 綠色 |

### 篩選和搜尋

1. **狀態篩選**
   - 點擊狀態標籤篩選特定狀態的對話
   - 可選擇「全部」、「待處理」、「處理中」、「已結束」

2. **平台篩選**
   - 選擇特定平台的對話
   - 支援 LINE、Facebook 或全部平台

3. **搜尋功能**
   - 在搜尋框輸入客戶名稱或訊息內容
   - 系統會即時顯示符合的對話

### 對話操作

#### 開啟對話
- 點擊對話列表中的任一對話
- 對話詳情會在右側顯示

#### 指派對話
1. 選擇待處理的對話
2. 點擊「指派給我」按鈕
3. 對話狀態會變更為「處理中」

#### 轉移對話
1. 在對話詳情中點擊「轉移」按鈕
2. 選擇要轉移的客服人員
3. 確認轉移操作

#### 結束對話
1. 在對話詳情中點擊「結束對話」按鈕
2. 確認結束操作
3. 對話狀態會變更為「已結束」

## 訊息處理

### 查看訊息

在對話詳情中，您可以看到：

- **訊息時間軸** - 按時間順序顯示所有訊息
- **訊息類型** - 文字、圖片、貼圖等不同類型
- **發送者** - 客戶或客服人員
- **訊息狀態** - 已發送、已讀等狀態

### 發送訊息

#### 發送文字訊息
1. 在訊息輸入框中輸入回覆內容
2. 點擊「發送」按鈕或按 Enter 鍵
3. 訊息會立即發送給客戶

#### 延遲發送訊息 ⭐ 新功能
1. **設定延遲時間**
   - 在訊息輸入框下方選擇延遲時間 (1-120 秒)
   - 可選擇快速預設：5s, 10s, 15s, 30s, 60s, 120s
   - 或手動輸入自訂時間

2. **發送延遲訊息**
   - 輸入訊息內容
   - 設定延遲時間
   - 點擊「延遲發送」按鈕
   - 系統會顯示預計發送時間

3. **管理待發送訊息**
   - 查看待發送列表，顯示所有排程訊息
   - 實時倒數計時，顏色編碼狀態 (綠色/橙色/紅色)
   - 可隨時撤回未發送的訊息

4. **撤回延遲訊息**
   - 在撤回時限內點擊「撤回」按鈕
   - 系統會立即取消發送並記錄操作
   - 撤回操作會記錄在系統日誌中

#### 發送圖片
1. 點擊訊息輸入框旁的「📎」按鈕
2. 選擇要上傳的圖片檔案
3. 確認發送

#### 使用快速回覆
1. 點擊「快速回覆」按鈕
2. 選擇預設的回覆模板
3. 可編輯內容後發送

### 訊息類型處理

#### 文字訊息
- 直接顯示訊息內容
- 支援表情符號和特殊字符

#### 圖片訊息
- 顯示縮圖，點擊可放大查看
- 支援 JPG、PNG、GIF 格式

#### 貼圖訊息
- 顯示貼圖圖片
- 包含貼圖包資訊

#### 位置訊息
- 顯示地圖位置
- 包含地址資訊

## 檔案附件管理

### 上傳檔案附件

#### 支援的檔案類型
- **圖片檔案**: JPG, PNG, GIF (最大 10MB)
- **文件檔案**: PDF, DOC, DOCX (最大 10MB)
- **其他檔案**: 根據系統設定

#### 上傳步驟
1. **選擇檔案**
   - 點擊訊息輸入框旁的「📎」迴紋針圖示
   - 選擇要上傳的檔案
   - 可同時選擇多個檔案

2. **檔案預覽**
   - 系統會顯示選中檔案的名稱和大小
   - 可以單獨移除不需要的檔案
   - 檔案會在發送前進行驗證

3. **發送附件**
   - 輸入訊息內容（可選）
   - 點擊「發送」按鈕
   - 檔案會先上傳，然後與訊息一起發送

### 檔案管理

#### 查看附件
- 在對話中點擊檔案附件可以預覽或下載
- 圖片檔案會直接顯示縮圖
- 文件檔案會顯示檔案圖示和名稱

#### 下載檔案
1. 點擊要下載的檔案附件
2. 選擇「下載」選項
3. 檔案會下載到您的裝置

#### 檔案安全
- 所有檔案都經過安全檢查
- 只有授權用戶可以存取檔案
- 檔案存取會記錄在系統日誌中

## 團隊管理

### 團隊概覽

在團隊管理頁面，您可以查看：

- **團隊統計**
  - 總成員數
  - 活躍成員數
  - 待處理邀請數
  - 管理員數量

### 成員管理

#### 查看成員列表
- 顯示所有團隊成員的基本資訊
- 包含姓名、電子郵件、角色、狀態
- 顯示最後登入時間

#### 管理成員
1. **更新角色**
   - 點擊成員卡片上的角色下拉選單
   - 選擇「管理員」或「客服」
   - 確認變更

2. **切換狀態**
   - 點擊「啟用」/「停用」按鈕
   - 停用的成員無法登入系統
   - 可隨時重新啟用

3. **重設密碼**
   - 點擊「重設密碼」按鈕
   - 系統會生成新密碼並發送給成員
   - 成員首次登入時需要更改密碼

4. **移除成員**
   - 點擊「移除」按鈕
   - 確認移除操作
   - 被移除的成員將無法存取系統

### 邀請管理

#### 邀請新成員
1. **填寫邀請表單**
   - 輸入新成員的電子郵件
   - 輸入姓名
   - 選擇角色（管理員/客服）

2. **發送邀請**
   - 點擊「發送邀請」按鈕
   - 系統會發送邀請郵件
   - 同時生成 QR 碼邀請連結

#### 管理邀請
1. **查看邀請狀態**
   - 待處理：邀請已發送，等待接受
   - 已過期：邀請超過 7 天未接受
   - 已使用：邀請已被接受

2. **重新發送邀請**
   - 點擊「重新發送」按鈕
   - 系統會發送新的邀請郵件

3. **複製邀請連結**
   - 點擊「複製連結」按鈕
   - 可以透過其他方式分享邀請連結

4. **取消邀請**
   - 點擊「取消」按鈕
   - 邀請連結將失效

### 邀請接受流程

#### 接受邀請
1. **點擊邀請連結**
   - 從郵件或 QR 碼進入邀請頁面
   - 系統會驗證邀請的有效性

2. **填寫註冊資訊**
   - 確認姓名和電子郵件
   - 設定登入密碼
   - 確認密碼

3. **完成註冊**
   - 點擊「接受邀請」按鈕
   - 系統會自動登入
   - 開始使用系統

## 即時協作功能

### WebSocket 即時通訊

系統提供企業級的即時協作功能：

#### 即時狀態同步
- **打字狀態**: 實時顯示團隊成員正在輸入
- **線上狀態**: 即時更新成員在線狀態
- **對話狀態**: 跨設備同步對話處理狀態
- **訊息同步**: 多人同時查看時的即時訊息更新

#### 多人協作
1. **同時查看對話**
   - 多個客服可同時查看同一對話
   - 實時顯示其他成員的操作狀態
   - 避免重複回覆的智能提醒

2. **協作指示器**
   - 顯示正在查看對話的其他成員
   - 打字狀態實時提示
   - 操作衝突預警

3. **即時通知**
   - 新訊息即時推送
   - 對話指派即時通知
   - 系統狀態變更通知

### 對話房間管理

每個對話都有專屬的協作空間：

#### 房間功能
- **成員管理**: 控制誰可以參與對話
- **權限控制**: 基於角色的操作權限
- **歷史記錄**: 完整的協作歷史追蹤
- **狀態廣播**: 向所有參與者廣播狀態變更

## 企業級功能

### 訊息撤回機制

系統提供靈活的訊息撤回功能：

#### 撤回設定
1. **撤回時間設定**
   - 可設定 0-120 秒的撤回時間
   - 管理員可調整全域撤回時間
   - 支援角色別的撤回權限

2. **撤回操作**
   - 發送訊息後顯示撤回按鈕
   - 倒數計時顯示剩餘撤回時間
   - 一鍵撤回，自動通知客戶

3. **撤回統計**
   - 撤回率統計和分析
   - 個人撤回使用記錄
   - 團隊撤回趨勢分析

### QR Code 自動指派

#### QR Code 生成
1. **團隊專屬 QR Code**
   - 每個團隊可生成專屬 QR Code
   - 支援自訂 QR Code 樣式和內容
   - 可設定 QR Code 過期時間

2. **自動指派規則**
   - 通過 QR Code 加入的客戶自動指派到對應團隊
   - 支援負載平衡的自動分配
   - 可設定指派優先級和條件

3. **使用統計**
   - QR Code 掃描次數統計
   - 轉換率和效果分析
   - 來源追蹤和分析

### 對話轉移系統

#### 轉移功能
1. **團隊間轉移**
   - 將對話從一個團隊轉移到另一個團隊
   - 保持完整的對話歷史記錄
   - 自動通知相關人員

2. **轉移歷史**
   - 完整的轉移記錄追蹤
   - 轉移原因和備註記錄
   - 轉移效果統計分析

3. **權限控制**
   - 基於角色的轉移權限
   - 跨團隊轉移需要審批
   - 轉移操作日誌記錄

### 權限管理系統

#### 角色權限
1. **管理員 (Admin)**
   - 完整的系統管理權限
   - 所有團隊和對話的存取權
   - 系統設定和配置權限

2. **經理 (Manager)**
   - 團隊管理權限
   - 團隊內對話的完整存取
   - 團隊統計和報表權限

3. **客服 (Agent)**
   - 指派對話的處理權限
   - 基本的客戶資料查看權限
   - 訊息發送和接收權限

#### 資料隔離
- **團隊隔離**: 不同團隊間的資料完全隔離
- **權限檢查**: 每個操作都進行即時權限驗證
- **存取日誌**: 完整的資料存取記錄

### 線上狀態

系統會顯示所有客服人員的線上狀態：

- 🟢 **線上** - 目前活躍使用系統
- 🟡 **忙碌** - 正在處理對話
- ⚪ **離線** - 未登入或已登出
- 🔵 **協作中** - 正在與其他成員協作

## 常見問題

### Q1: 為什麼看不到新的客戶訊息？

**可能原因：**
- 網路連線問題
- 瀏覽器快取問題
- 權限設定問題

**解決方法：**
1. 檢查網路連線
2. 重新整理頁面（F5）
3. 清除瀏覽器快取
4. 聯繫管理員檢查權限

### Q2: 如何處理客戶的緊急問題？

**處理步驟：**
1. 立即回覆客戶確認收到訊息
2. 將對話標記為「緊急」
3. 如需協助，使用求助功能
4. 記錄處理過程在備註中

### Q3: 訊息發送失敗怎麼辦？

**檢查項目：**
1. 確認網路連線正常
2. 檢查訊息內容是否符合平台規範
3. 確認客戶帳號狀態正常
4. 重新嘗試發送

### Q4: 如何查看歷史對話記錄？

**查看方法：**
1. 在客戶資訊面板點擊「歷史記錄」
2. 選擇時間範圍
3. 瀏覽所有歷史對話

### Q5: 系統運行緩慢怎麼辦？

**優化建議：**
1. 關閉不必要的瀏覽器分頁
2. 清除瀏覽器快取
3. 使用 Chrome 或 Firefox 瀏覽器
4. 檢查網路速度

### Q6: WebSocket 連接失敗怎麼辦？

**檢查步驟：**
1. 確認瀏覽器支援 WebSocket
2. 檢查防火牆設定
3. 重新整理頁面重新連接
4. 聯繫系統管理員檢查服務狀態

### Q7: 訊息撤回失敗怎麼辦？

**可能原因：**
1. 超過撤回時間限制
2. 訊息已被客戶讀取
3. 網路連接問題
4. 權限不足

**解決方法：**
1. 檢查撤回時間設定
2. 確認網路連接正常
3. 聯繫管理員檢查權限設定

### Q8: 無法看到其他成員的協作狀態？

**檢查項目：**
1. WebSocket 連接是否正常
2. 是否在同一個對話房間
3. 權限設定是否正確
4. 瀏覽器是否支援即時功能

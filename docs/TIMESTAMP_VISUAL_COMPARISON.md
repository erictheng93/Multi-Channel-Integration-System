## ✨ 关键改进亮点

### 1. **智能显示逻辑**

```
IF 消息发送日期 == 今天
  THEN 显示 "HH:MM"               (例: 14:30)
ELSE
  THEN 显示 "YYYY/MM/DD HH:MM"    (例: 2025/01/27 14:30)
```

### 2. **24小时制格式**

```
❌ 原格式：上午09:30, 下午02:15, 下午11:59
✅ 新格式：09:30,    14:15,    23:59
```

### 3. **完整日期信息**

```
❌ 原格式：11:09 (无法知道日期)
✅ 新格式：2025/01/27 11:09 (完整追踪)
```

# NotificationList 手动功能验证指南

## 📋 概述

本指南用于手动验证 NotificationList 重构后的所有功能是否正常工作。

---

## 🚀 前置准备

### 1. 启动开发环境

```bash
# 终端 1 - 启动后端
npm run dev

# 终端 2 - 启动前端
cd frontend
npm run dev
```

### 2. 登录系统

1. 访问 `http://localhost:3000`
2. 使用管理员或普通用户账号登录
3. 导航到通知中心页面 `/notifications`

---

## ✅ 功能验证清单

### 📍 测试区域 1: 页面加载与基本显示

#### 测试 1.1: 页面加载
- [ ] 页面能够成功加载，没有控制台错误
- [ ] 页面标题显示为 "通知中心"
- [ ] 页面布局正常，无样式错乱

#### 测试 1.2: 通知列表显示
- [ ] 通知列表能够正常显示
- [ ] 通知卡片包含所有必要信息（标题、内容、时间、类型图标）
- [ ] 已读/未读状态正确显示（未读通知有视觉标记）

#### 测试 1.3: 统计信息显示
- [ ] 页面顶部显示通知统计信息
- [ ] 统计数字与实际通知数量一致
- [ ] 未读通知计数正确

---

### 📍 测试区域 2: 过滤功能

#### 测试 2.1: 通知类型过滤
1. 点击"类型"下拉选择器
2. 选择"新訊息"
3. 验证：
   - [ ] 列表只显示"新訊息"类型的通知
   - [ ] 过滤标签显示"有篩選條件"

#### 测试 2.2: 优先级过滤
1. 点击"优先级"下拉选择器
2. 选择"緊急"
3. 验证：
   - [ ] 列表只显示"緊急"优先级的通知
   - [ ] 过滤标签显示正确

#### 测试 2.3: 已读状态过滤
1. 点击"已讀狀態"下拉选择器
2. 选择"未讀"
3. 验证：
   - [ ] 列表只显示未读通知
   - [ ] 过滤生效

#### 测试 2.4: 多重过滤
1. 同时选择类型、优先级和已读状态
2. 验证：
   - [ ] 列表显示同时满足所有条件的通知
   - [ ] 过滤逻辑正确

#### 测试 2.5: 清除过滤
1. 应用多个过滤条件
2. 点击"清除篩選"按钮
3. 验证：
   - [ ] 所有过滤条件被清除
   - [ ] 列表恢复显示所有通知
   - [ ] "有篩選條件"标签消失

---

### 📍 测试区域 3: 通知操作

#### 测试 3.1: 标记单个通知为已读
1. 找到一个未读通知
2. 点击通知卡片上的"標記已讀"按钮
3. 验证：
   - [ ] 通知状态变为已读（视觉标记消失）
   - [ ] 显示成功提示消息"已標記為已讀"
   - [ ] 未读计数减 1

#### 测试 3.2: 标记全部为已读
1. 确保有多个未读通知
2. 点击页面顶部的"全部已讀"按钮
3. 验证：
   - [ ] 所有通知状态变为已读
   - [ ] 显示成功提示消息"已將所有通知標記為已讀"
   - [ ] 未读计数变为 0
   - [ ] 按钮在操作过程中显示加载状态

#### 测试 3.3: 删除通知
1. 找到一个通知
2. 点击通知卡片上的"刪除"按钮
3. 验证：
   - [ ] 通知从列表中移除
   - [ ] 显示成功提示消息"通知已刪除"
   - [ ] 总通知计数减 1

#### 测试 3.4: 点击通知跳转
1. 找到一个包含对话 ID 的通知（如"新訊息"、"客戶回覆"等）
2. 点击通知卡片
3. 验证：
   - [ ] 自动标记为已读（如果之前未读）
   - [ ] 页面跳转到对应的对话详情页面
   - [ ] 对话 ID 正确

---

### 📍 测试区域 4: 分页功能

#### 测试 4.1: 加载更多
1. 滚动到通知列表底部
2. 如果有更多通知，应该看到"載入更多"按钮
3. 点击"載入更多"按钮
4. 验证：
   - [ ] 加载更多通知
   - [ ] 按钮在加载时显示加载动画
   - [ ] 新通知追加到列表底部
   - [ ] 显示已加载数量和总数量

#### 测试 4.2: 全部加载完成
1. 多次点击"載入更多"直到加载所有通知
2. 验证：
   - [ ] "載入更多"按钮消失
   - [ ] 显示"已顯示 X / X 則通知"

---

### 📍 测试区域 5: 键盘导航

#### 测试 5.1: 方向键导航
1. 确保通知列表有至少 3 个通知
2. 按下 `ArrowDown` 键
3. 验证：
   - [ ] 第一个通知获得焦点（高亮显示）
4. 继续按 `ArrowDown`
5. 验证：
   - [ ] 焦点向下移动到下一个通知
   - [ ] 滚动自动调整以保持焦点可见
6. 按 `ArrowUp` 键
7. 验证：
   - [ ] 焦点向上移动到上一个通知

#### 测试 5.2: Enter 键选择
1. 使用方向键导航到某个通知
2. 按下 `Enter` 键
3. 验证：
   - [ ] 触发通知点击操作
   - [ ] 如果通知包含对话链接，跳转到对应页面

#### 测试 5.3: Escape 键取消焦点
1. 使用方向键选中某个通知
2. 按下 `Escape` 键
3. 验证：
   - [ ] 通知焦点被清除
   - [ ] 没有通知处于高亮状态

---

### 📍 测试区域 6: 设置功能

#### 测试 6.1: 打开设置面板

   - [ ] 设置面板弹出/显示

#### 测试 6.2: 修改设置

#### 测试 6.3: 关闭设置面板
1. 打开设置面板
2. 点击关闭按钮或面板外部
3. 验证：
   - [ ] 设置面板关闭

#### 测试 7.2: WebSocket 连接状态
1. 检查浏览器控制台
